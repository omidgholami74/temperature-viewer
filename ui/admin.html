Module

Live sampling, noise filter and heartbeat. Saved as /settings.json on the board and applied on the next frame; no reflash.

Sensor source: —

The 400 ms default leaves room for five reads per channel and a 6000 µs gap (~76 ms for three MAX31855s). Lower the sample rate before increasing the read gap.

Noise checklist

If readings still jump: use a twisted, shielded K-type pair with the shield grounded at one end; keep thermocouple leads away from mains and SSR wiring; add 100 nF at the MAX31855 supply and a 1 kΩ + 0.1 µF RC at T+/T−; power the board from a clean 5 V supply. In firmware, try Quiet (9 reads, 12 ms gap, EMA 0.2) and a slower frame. Do not filter so hard that the furnace response looks delayed.

Quick presets

Public dashboard

The public page has no admin link and no filter controls. These values are applied to every visitor from the server.

The threshold is a percentage of the previous reading. A lower value filters more aggressively; 60% ignores only severe one-frame glitches.

Board profile

An operator-owned name, location and note. This is separate from the firmware name, so a heartbeat never overwrites it.

Upload source bundle

Upload application and helper .py files for one board variant. The server verifies names and hashes, then swaps the bundle atomically; the board only receives it when you queue an OTA update. Network and boot core files stay on the board and are refused by the browser uploader, so an accidental bad app upload cannot remove the recovery path.

Requires FURNACE_ADMIN_KEY. Application files are accepted; boot.py, wifi.py, ingest.py, supervisor.py, ota.py, device.py, settings.py and config.py are protected. The board keeps its working network core, applies the uploaded app, and rolls back if it cannot confirm itself.

Furnaces

Labels live on the server and are shown by the dashboard. Enabled and calibration are queued to the board: a disabled furnace is an empty slot with no fault. The base offset applies outside every band; a temperature band replaces it between its min and max.

Calibration helper

Enter the real temperature from a reference thermometer and the value currently shown. The new offset is added to the base offset, so two-point checks can be repeated. For a nonlinear probe, add one band per working range above.

Wi-Fi

Queues new credentials for the board. It saves them, reboots and joins that network; config.py is not changed.

The password is stored on the server until the board acknowledges the command. Use a dedicated network for the furnace.

Firmware source

Choose the published source bundle to run. The board updates only when you press the button: the heartbeat delivers the command, then every file is verified, staged and applied on reboot.
